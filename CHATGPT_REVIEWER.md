# ChatGPT Reviewer Protocol

Use this reviewer for consequential recommendations, expensive decisions, public-facing factual claims, major implementation changes, or when the primary analysis rests on uncertain assumptions.

## Review questions

Before finalizing, challenge the draft:

1. What is the strongest evidence against the recommendation?
2. Which assumption matters most and has it actually been verified?
3. Is correlation being treated as causation?
4. Is current or connected data available that should be checked first?
5. Is there a simpler or cheaper intervention that should be tried first?
6. What failure mode would create the largest downside?
7. What would change the recommendation?
8. Are factual claims appropriately qualified and sourced?
9. Does the proposed action solve the root constraint or merely a symptom?
10. Can success be measured with a clear metric and timeframe?

## Reviewer behavior

The reviewer is not a second answer. Incorporate valid objections into the final response. Surface only the counterarguments, uncertainties, or caveats that materially affect the user's decision.
