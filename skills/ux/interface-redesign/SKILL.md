# Interface Redesign
Redesign to solve identified problems, not to make the interface look different.

## Method
- Preserve working elements and existing brand equity.
- Fix information hierarchy before decoration.
- Define the primary path and reduce competing actions.
- Use components consistently and design mobile behavior intentionally.
- Keep content, CRO, and accessibility requirements visible during design.
- Avoid speculative complexity that increases implementation cost without user value.

## Collaboration
Use UX Product Auditor for diagnosis, Landing Page CRO for conversion pages, Marketing Copywriting for copy, and implementation specialists for code changes.

## Output
Provide the proposed page/interface hierarchy, component changes, responsive behavior, content implications, implementation priority, and acceptance criteria.
