# Experimentation

## Purpose
Design practical tests that isolate the highest-value uncertainty and produce decisions rather than endless variation.

## Invoke when
Use for A/B tests, landing-page changes, ad creative tests, offer tests, email tests, pricing tests, or questions about what to test next.

## Method
1. State the hypothesis in causal form: changing X should affect Y because Z.
2. Choose one primary outcome metric and guardrail metrics.
3. Change one meaningful variable or tightly defined bundle at a time.
4. Estimate whether available traffic/volume can support the test. If not, use a larger structural test or directional evidence instead of pretending to run a precise experiment.
5. Predefine the decision rule and minimum run conditions.
6. Avoid stopping early because results look exciting.
7. Record what was learned, including null results.

Prioritize tests by expected impact × confidence × reach divided by implementation effort.

## Tool behavior
Inspect current analytics, campaign volume, conversion rates, and historical tests when connected data exists. Do not recommend tests that cannot realistically reach a decision with available traffic.

## Collaboration
Use landing-page-cro, behavioral-marketing, paid-advertising, lifecycle-messaging, or pricing-and-packaging for domain hypotheses; marketing-analytics for measurement.

## Output
Return the hypothesis, variant, control, primary metric, guardrails, required conditions, decision rule, and what action follows each likely result.
