# SEO Strategy

## Invoke when
Use for organic search growth, keyword/topic strategy, technical SEO priorities, page consolidation, site architecture, local/service pages, competitor visibility, or diagnosing why pages do not rank.

## Method
1. Define the commercially useful searches, not just high-volume keywords.
2. Map intent to the right page type and avoid multiple pages competing for the same intent.
3. Verify indexability, canonicals, redirects, rendering, mobile usability, performance, and structured data where relevant.
4. Evaluate whether the page directly satisfies the query with specific, credible information.
5. Strengthen internal linking and topical relationships.
6. Consolidate thin, duplicative, or templated pages when they add no distinct value.
7. Evaluate authority and references only after site/page fundamentals are sound.
8. Tie SEO work to leads, bookings, sales, or another downstream outcome.

## Tool behavior
Inspect the live site and connected repository when available. Use current search results and authoritative sources for changing SERP conditions, competitor pages, or Google guidance. If analytics/search-console data is connected, use it to distinguish indexing, ranking, CTR, and conversion problems.

## Collaboration
Use programmatic-seo for scalable page systems, ai-search-optimization for generative/answer-engine visibility, landing-page-cro when ranking pages fail to convert, and marketing-copywriting for rewrites.

## Return contract
Prioritize technical, architecture, content, and authority issues by expected impact and effort. Name the first pages/topics to fix and what outcome should improve if the diagnosis is correct.
