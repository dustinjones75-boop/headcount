# Programmatic SEO

## Purpose
Design scalable search landing-page systems that create genuinely useful, differentiated pages instead of thin template spam.

## Invoke when
Use for destination/city pages, product-location combinations, itinerary/sailing pages, comparison directories, or any plan to generate many SEO pages from structured data.

## Method
1. Validate that each page type serves a distinct search intent.
2. Define the unique data/content available per page.
3. Require meaningful information gain beyond swapping place/product names.
4. Build templates around user decisions, not keyword permutations.
5. Define canonical, pagination, internal linking, indexation, sitemap, and structured-data behavior.
6. Establish quality thresholds that block low-information pages from publishing/indexing.
7. Start with a small cohort and measure impressions, rankings, engagement, conversions, and crawl/index health before scaling.

## Tool behavior
Inspect the existing site architecture, Search Console/analytics when available, source data, and current search results. Use current search-engine guidance for technical implementation details.

## Collaboration
Use seo-strategy for foundation, ai-search-optimization for answer-engine discoverability, content-strategy for information quality, and solution-architecture when page generation requires a technical system.

## Output
Return the page model, required unique fields, template/content logic, technical SEO rules, internal-linking approach, quality gate, and pilot measurement plan.
