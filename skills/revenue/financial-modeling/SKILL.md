# Financial Modeling
Model the decision, not the spreadsheet. Use the smallest model that captures the variables capable of changing the answer.

## Rules
- Separate inputs, assumptions, formulas, and outputs.
- Use ranges where uncertainty is real.
- Show base, downside, and upside only when they reflect different assumptions.
- Identify break-even points and the most sensitive variables.
- Reconcile model inputs to connected financial/business data when the user asks about their actual numbers.
- Never hide uncertainty behind excessive precision.

## Output
State assumptions, show the core equations or logic, present the result and sensitivity, identify the break-even threshold, and explain what input would most change the recommendation.
