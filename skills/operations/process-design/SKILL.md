# Process Design
Before automating a process, simplify it.

## Method
- Define the trigger, desired outcome, and customer/user of the process.
- Map the current steps and identify delays, rework, duplicate entry, unclear handoffs, and unnecessary approvals.
- Eliminate before optimizing; optimize before automating.
- Give every step an owner and a completion condition.
- Define exception paths and escalation rules.
- Add only metrics that can drive action.

## Output
Show the current-state problem, proposed future-state flow, ownership, exceptions, automation candidates, and the few metrics that prove the process improved.
